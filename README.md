Entry for the [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3)
competition on make.fun: a single hilarious line of at most 200 characters,
judged pairwise by an AI comedy editor on first-read laugh, surprise,
economy, freshness, and clean wording.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> I asked my plants what they thought of me; they died rather than answer.

The setup sounds like a harmless bit of small talk with houseplants; the
punchline reframes their usual dying as a deliberate refusal to answer —
a turn the reader does not see coming, in 72 characters. The output file
is written world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
